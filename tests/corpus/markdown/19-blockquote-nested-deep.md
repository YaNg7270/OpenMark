# 嵌套引用与中英混排

> 第一层引用给出整体结论：渲染管线（rendering pipeline）的瓶颈通常出现在布局阶段，而不是绘制阶段。
>
> > 第二层引用补充测量方法：使用 tracing 工具记录每一帧的 layout 与 paint 耗时，再对比 cache miss 的比例。
> >
> > > 第三层引用给出具体阈值：当 layout 耗时超过 8 毫秒时，滚动就会出现可感知的掉帧，必须优先优化。

> 另一组引用转向网络层：QUIC 在握手阶段引入了 0-RTT，但首次连接仍然需要一次完整往返。
>
> > 继续深入：拥塞控制算法（congestion control）决定窗口增长曲线，BBR 与 CUBIC 的行为差异很大。
> >
> > > 最深一层指出：丢包率高于 2% 时，无论使用哪种算法，吞吐都会明显下降。
