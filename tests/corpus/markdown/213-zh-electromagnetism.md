# 电磁学纲要

电磁学研究电荷、电流与其周围场的相互作用。它从静电现象出发，经由电流与磁场，最终由麦克斯韦方程组统一。这一理论不仅解释了所有经典电磁现象，还预言了电磁波的存在，并直接促成了相对论的诞生。

## 电荷与库仑定律

静止电荷之间通过电场相互作用，相互作用力的大小与电荷量之积成正比，与距离的平方成反比。

1. 力是矢量，多个电荷的作用需要按矢量叠加。
2. 叠加原理使复杂电荷分布的处理成为可能。
3. 连续分布用线电荷密度、面电荷密度与体电荷密度描述。

电场定义为检验电荷所受的力与其电量之比。这个定义把力的作用从“隔空传递”改写成“先有场，场再施力”，为后来的场论铺路。

## 高斯定理

高斯定理指出，闭合曲面上的电通量只取决于面内包围的净电荷，与电荷的具体位置和分布无关。

| 对称性 | 适用曲面 | 常见用途 |
| --- | --- | --- |
| 球对称 | 同心球面 | 点电荷、均匀带电球壳 |
| 柱对称 | 同轴柱面 | 无限长带电直线 |
| 面对称 | 平行平面 | 无限大带电平板 |

选择高斯面时必须让场在面上要么垂直、要么平行，否则通量积分无法简化。这是使用该定理的核心技巧，也是初学者最常忽略的前提。

> 高斯定理对任意闭合曲面都成立，但只有当对称性足够高时，它才能直接解出场强。否则它仍然正确，却无法化简为简单的代数关系。

## 电流与磁场

电流产生磁场，磁场对运动电荷施力。安培环路定理描述电流与磁场的关系，比奥萨伐尔定律则给出电流元产生的磁场贡献。

- 磁场对运动电荷的力方向垂直于速度，因此不做功。
- 带电粒子在匀强磁场中做圆周或螺旋运动，半径与动量成正比。
- 平行电流同向相吸、反向相斥，这是电流定义的历史依据。

法拉第电磁感应定律指出，闭合回路中的感应电动势取决于磁通量的变化率。变化的来源可以是磁场强弱、回路面积或相对取向，三者效果等价。楞次定律进一步给出发应电流的方向：它总是阻碍磁通量的变化。

## 麦克斯韦方程组

麦克斯韦方程组由四个方程构成，分别描述电场的源、磁场的无源性、变化磁场产生电场，以及变化电场与电流共同产生磁场。

1. 高斯电场定律：电通量由净电荷决定。
2. 高斯磁场定律：不存在磁单极子，磁通量恒为零。
3. 法拉第定律：变化的磁场激发电场。
4. 安培麦克斯韦定律：电流与位移电流共同激发磁场。

位移电流是麦克斯韦引入的关键修补项，它保证了电流连续性，也使方程组在无源区域支持波动解。由此推得的电磁波速度与光速一致，从而揭示了光的电磁本质，并进一步说明光速在所有惯性系中相同，这直接动摇了绝对时空的假设。
