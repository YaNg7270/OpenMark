# 外部链接示例

技术文档经常需要把读者引向权威来源，而不是把大段内容抄进正文。下面的四个
链接分别指向前端标准、系统编程教材、版本控制工具手册以及网络协议的正式
文本，覆盖了日常开发中最常见的外部引用类型。

前端开发者几乎每天都会查阅 MDN 的 CSS 参考页面，它对属性、取值与浏览器
兼容性都有清晰说明，参见 [MDN CSS 参考](https://developer.mozilla.org/en-US/docs/Web/CSS)。

学习系统编程时，《The Rust Programming Language》常被作为第一本教材，其
在线版本可以免费阅读，见 [Rust 程序设计语言](https://doc.rust-lang.org/book/)。

版本控制方面，Git 官方手册按子命令组织内容，适合在遇到具体问题时按需查阅，
链接是 [Git 文档](https://git-scm.com/docs)。

网络协议则更适合直接读原始规范，因为规范中的措辞往往比二手解释更精确，
例如 [RFC 9110](https://www.rfc-editor.org/rfc/rfc9110) 定义了 HTTP 语义。

这四个链接都是普通的行内链接，而不是图片：它们的目标是网页，读者点击后
会在浏览器中打开，因此渲染器只需生成锚点，不需要处理任何资源加载。
