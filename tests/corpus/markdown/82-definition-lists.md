# 术语定义列表示例

定义列表用于把术语与其解释并排写出，常见于术语表、API 参考和教学内容。
下面的第一组条目介绍渲染管线里的两个核心概念，中文与拉丁术语混排。

Render Pipeline

: 渲染管线，指从 Markdown 源文本到最终 HTML 或 PDF 输出的完整处理流程。

Abstract Syntax Tree

: 抽象语法树，是解析阶段产出、供后续变换与渲染阶段消费的中间结构。

一段普通段落可以让解析器结束上面这一定义列表，从而开始新的一组条目。

Incremental Parse

: 增量解析，指文档编辑后只重新处理发生变化的部分，以降低重解析开销。

Virtual DOM

: 虚拟 DOM，是渲染器在内存中维护的轻量节点树，用来减少对真实文档对象的操作次数。

最后一句话说明：定义列表的判定依赖术语行与其后以冒号开头的解释行之间的相邻关系。
