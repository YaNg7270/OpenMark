# Unordered Lists

An unordered list uses a marker character followed by at least one space.

- Parsers accept several interchangeable marker characters.
- The marker must be followed by a space to start an item.
- The rendered output discards the specific marker that was used.

The asterisk form is historically the oldest and still appears in many plain-text documents.

* An asterisk bullet renders identically to a hyphen bullet.
* Mixing markers inside one list is legal but discouraged.
* Most formatters normalise every bullet to a single dash.

The plus sign is the least common of the three markers.

+ A plus bullet is rare but fully supported.
+ Consistency inside one list matters more than the choice of marker.
+ Reviewers usually ask for a single style per document.
