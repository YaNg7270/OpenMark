# Tight And Loose Lists

A tight list keeps its items adjacent, so the renderer wraps each item in a bare list element without an enclosing paragraph.

- Compile the sources into object files.
- Link the objects into a single binary.
- Strip the debug symbols before shipping.

A loose list inserts a blank line between items, which wraps every item in its own paragraph and adds vertical spacing around it.

- Compile the sources into object files.

- Link the objects into a single binary.

- Strip the debug symbols before shipping.
