# 自动链接的使用

自动链接让作者可以直接把尖括号里的地址写进正文，而无需再提供一个链接文字。
对文档站点而言，这种方式最省事：地址本身就是可读的内容，读者一眼就能看出
目标域名与路径。<https://example.com/docs> 是最基本的形式，渲染器会把它
转换成一个可点击的链接，并保留原始的显示文本。

电子邮件地址的写法与网址类似，只是需要 mailto 前缀来告诉渲染器该协议。
协作场景中常把团队邮箱写在页脚：<mailto:team@example.com>，这样读者点击后
就能直接打开邮件客户端，而不必手动复制地址。

同样地，当一句话中间需要引用某个文档页面时，也可以把地址直接嵌在句子内部，
例如构建日志的说明可以写成：详见 <https://example.com/build/logs> 一节的排障
步骤。此时链接前后的标点仍然属于正文，不会因为尖括号而丢失。

需要注意的是，尖括号内的地址必须包含协议前缀，无论网址还是邮件地址都一样，
但裸域名不会被识别。若地址中包含空格或全角字符，渲染器通常会放弃自动链接，
把整段文本原样输出，以免生成错误的目标。

因此，在中文技术文档里使用自动链接时，应当确保地址两侧留有适当间距，并
避免把句末标点写进尖括号内部。
