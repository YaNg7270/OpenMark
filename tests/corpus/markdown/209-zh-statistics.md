# 统计学基本方法

统计学研究如何从有限的样本推断总体性质，并量化这种推断的不确定性。它与概率论的推理方向相反：概率论从已知分布推结果，统计学从观测结果反推分布参数。

## 抽样分布

推断的基础是抽样分布，即统计量在重复抽样下的分布。理解抽样分布是理解一切区间估计与检验的前提。

- 样本均值本身是随机变量，它的期望等于总体均值。
- 样本均值的标准差称为标准误，它随样本量的平方根反比下降。
- 增大样本量只能缩小标准误，不能消除系统性的抽样偏差。

| 统计量 | 用途 | 关键性质 |
| --- | --- | --- |
| 样本均值 | 估计中心位置 | 无偏，对极端值敏感 |
| 样本方差 | 估计离散程度 | 分母用自由度修正后无偏 |
| 样本中位数 | 稳健的中心估计 | 抗离群点，效率略低 |

若总体近似正态或样本量足够大，样本均值近似服从正态分布，这正是中心极限定理的直接应用。

## 区间估计

点估计给出单一数值，但几乎不可能恰好命中真值，因此更有意义的是给出一个区间并附带置信水平。

置信水平的含义经常被误读。它描述的是构造方法的长期表现：如果反复抽样并每次构造区间，约有相应比例的区间会覆盖真值。它并不表示真值落在某个具体区间内的概率。

- 提高置信水平会使区间变宽。
- 增大样本量会使区间变窄。
- 减小总体波动同样使区间变窄。

> 置信区间与可信区间名字相近，含义却不同。前者基于重复抽样的频率解释，后者基于参数的先验分布。混用会导致对结论的过度解读。

## 假设检验

假设检验先设定一个待否证的原假设，再计算在假设成立时观测到当前或更极端结果的概率，即 p 值。

1. 明确原假设与备择假设，二者应当互补且事先确定。
2. 选择检验统计量，并确认其抽样分布。
3. 依据显著性水平作出判断。
4. 报告效应量与置信区间，而不只报告是否显著。

两类错误分别是错误拒绝真原假设与未能拒绝假原假设，它们的概率此消彼长，只能通过增大样本量同时压低。

## 小结

统计分析的正确性依赖于三项前提：抽样方式无偏、模型假设合理、结论不被选择性报告所污染。任何一项被破坏，p 值与置信区间都会失去意义。因此报告结果时应同时给出样本量、效应量与方法细节，让读者能够自行判断结论的可靠程度。

需要特别警惕多重比较：反复检验会显著抬高至少出现一次假阳性的概率。此外，显著性不等于重要性，一个统计显著但效应量极小的差异，在实际决策中可能毫无意义。
