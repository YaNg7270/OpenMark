# 中英混排与排版规范

中文技术写作经常需要在同一句话里插入拉丁术语，例如渲染管线会把 Markdown
源文本交给 parser 处理，再由 renderer 生成最终页面。此时最常见的排版约定是
在中文与拉丁文字之间留一个半角空格，让行内节奏更均匀。

标点方面，中文句子应当使用全角标点（，。；：），而不是把英文的逗号和句号直接
搬进来。例如：解析器先切分段落，再识别行内语法；两者顺序不能颠倒。全角标点
占据一个汉字宽度，与前后汉字的间距自然一致。

引用他人说法时，中文习惯使用书名号与引号（「」）。老师说：「先把结构写清楚，
再考虑样式。」这句话里的引号是成对出现的，左引号在句首，右引号在句末标点之前。

当一句话以拉丁缩写结尾时，标点归属需要判断：若整个句子是中文，就在缩写之后
加上全角句号；若括号内是完整英文句子，则括号内使用半角句号。这类细节看似琐碎，
却直接影响阅读时的停顿感。

数字与单位同样遵循类似规则：缓存命中率从 92% 提升到 97%，延迟从 120 ms 降到
40 ms。数字与中文之间留空格，数字与百分号之间不留空格，单位与数字之间留空格。

最后一点是行宽。中文没有词间空格，一行可以容纳更多字符，因此排版时通常把
正文行宽控制在 35 到 45 个汉字之间，以便在屏幕上保持良好的阅读节奏。
