# 分析化学方法

分析化学回答两个基本问题：样品中有什么，以及各组分有多少。前者称为定性分析，后者称为定量分析。无论采用哪种手段，结果都必须附带不确定度，否则数值本身没有意义。

## 滴定分析

滴定通过已知浓度的标准溶液与待测组分定量反应，由化学计量关系反推待测物的量。

1. 配制并标定标准溶液，确定其准确浓度。
2. 准确移取一定体积的待测液，加入合适的指示剂。
3. 缓慢滴加标准液，直至终点指示出现。
4. 记录消耗体积，按计量关系计算含量。

| 滴定类型 | 反应实质 | 常用基准物质 |
| --- | --- | --- |
| 酸碱滴定 | 质子转移 | 邻苯二甲酸氢钾 |
| 氧化还原滴定 | 电子转移 | 重铬酸钾 |
| 配位滴定 | 形成稳定配合物 | 碳酸钙 |
| 沉淀滴定 | 生成难溶沉淀 | 氯化钠 |

终点与等当点并不重合，二者之差构成指示剂误差。选择合适的指示剂，使变色范围落在滴定突跃之内，是减小该误差的关键。

## 光谱分析方法

光谱法利用物质与电磁辐射的相互作用来获取组成信息。

- 原子吸收光谱：基态原子吸收特征波长，适合金属元素的定量。
- 紫外可见光谱：分子中发色团吸收紫外或可见光，常用于浓度测定与结构初判。
- 红外光谱：分子振动能级跃迁，用于识别官能团。
- 核磁共振：核在外磁场中的能级分裂，用于推断碳氢骨架。

> 光谱定量大多遵循朗伯比尔定律：吸光度与浓度和光程之积成正比。但当浓度过高或存在相互作用时，该线性关系会偏离，因此标准曲线必须覆盖实际样品的浓度范围。

## 误差与数据处理

误差分为系统误差与随机误差。系统误差有确定来源，可被识别和校正；随机误差服从统计规律，只能通过重复测量减小。

1. 准确度反映测量均值与真值的接近程度，用系统误差描述。
2. 精密度反映多次测量之间的一致程度，用随机误差描述。
3. 精密度高不等于准确度高，二者必须分别评估。

对于通过多个独立量计算得到的结果，误差传递规律表明相对误差按各量的相对误差平方和开方合成，并乘以相应的灵敏度指数。这意味着计算式中的乘除与幂次运算会放大误差，而加减运算的误差传递则与绝对量有关。

## 小结

一次可靠的分析包含五个环节：样品前处理、测量、校准、数据处理与不确定度评定。任何一环被省略，结果都无法追溯。尤其需要注意的是，前处理的回收率与空白值常常是误差的主要来源，却最容易被忽视，因为它们不出现在最终的计算公式里。

因此，在设计实验时应优先提高那些灵敏度指数大、且在计算中反复出现的量的测量精度。把资源平均分配到所有测量上，往往不是最优策略。
