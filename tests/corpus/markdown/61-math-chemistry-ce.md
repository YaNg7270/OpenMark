# 化学方程式的排版

化学方程式与数学公式共享同一套排版系统，但反应箭头、状态标注和电荷符号让它们的写法略有不同。

燃烧反应是最常见的例子，甲烷在氧气中完全燃烧会生成二氧化碳和水。

$\ce{CH4 + 2O2 -> CO2 + 2H2O}$

可逆反应用双箭头表示，平衡的两侧分别标注反应物与生成物。

$\ce{N2 + 3H2 <=> 2NH3}$

离子反应需要标出电荷，上标中的正负号与数字共同决定离子的种类。

$\ce{Ca^2+ + CO3^2- -> CaCO3}$

物质的状态用括号写在化学式之后，可以让读者一眼看清相变过程。

$\ce{CaCO3(s) -> CaO(s) + CO2(g)}$

物理量配合单位书写时使用专门的命令，数值与单位之间的关系由排版系统自动处理。

$\pu{1.5 mol}$

温度同样可以用该命令表示，摄氏度的圈号也会一并排版出来。

$\pu{25 ^\circ C}$

本文件一共包含四个化学方程式和两个物理量，覆盖了燃烧、平衡、离子电荷以及状态标注这几种典型情形。

化学排版的关键在于把普通文本与命令区分开来，命令通常以反斜杠开头，后面跟着一串字母。

如果不小心漏掉反斜杠，系统就会把它当作一连串普通的英文字母来渲染，阅读体验会明显变差。

因此测试需要逐个核对命令是否被正确识别，并确认状态标注与电荷符号都保留在了原来的位置。

上面的例子里，反应物与生成物之间的箭头方向同样值得检查，因为它决定了反应是否被写成可逆的形式。

每一个化学式都写在同一行内，没有跨行的情况，这也是本文档用于计数测试的前提。

两条物理量同样保持简洁，数值与单位之间不留多余的空格。

上述内容共同构成了一个完整而自洽的化学排版样例。
