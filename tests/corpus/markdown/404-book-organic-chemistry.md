# 第 5 章 — 官能团、亲核取代与立体化学

有机化学本质上研究的是「碳骨架 + 官能团」这一对组合如何决定分子的性质与反应走向。
本章沿着从结构到反应的顺序展开：先在 §1 梳理常见官能团及其电子特征，再在 §2 讨论
饱和碳上的亲核取代机理，接着在 §3 说明取代与消除之间的竞争，然后在 §4 建立立体化学
的记号体系，最后在 §5 把机理与立体化学合起来分析真实反应。本章小结与练习位于末尾。

## 1. 官能团 Functional Groups

### 1.1 什么是官能团

官能团是分子中决定化学反应性的原子或原子团。碳骨架主要决定分子的形状与疏水性，
而官能团决定它在哪里发生反应、以多快的速度发生。理解官能团，关键是理解它的
**电子结构**：哪个原子缺电子（亲电中心），哪个原子富电子（亲核中心），以及哪些
键足够容易被极化和断裂。

### 1.2 常见官能团一览

下表按杂原子成键方式归类。记 $\sigma$ 为电负性差带来的极化程度，它直接影响反应活性。

| 官能团 | 结构式 | 极性 | 典型反应 |
| ------ | ------ | ---- | -------- |
| 羟基 | R–OH | 强极性，可氢键 | 取代、氧化、酯化 |
| 醚 | R–O–R′ | 弱极性 | 亲电断裂 |
| 羰基 | R₂C=O | 强极性 | 亲核加成 |
| 羧基 | R–COOH | 强极性，酸性 | 成酰胺、酯化 |
| 氨基 | R–NH₂ | 碱性 | 亲核取代、成酰胺 |
| 卤代 | R–X | 弱极性 | 亲核取代、消除 |
| 硝基 | R–NO₂ | 强吸电子 | 还原为氨基 |

官能团之间可以相互转化，这就是有机合成的核心思路：把一种容易引入的官能团当作
「把手」，再通过几步已知反应换到目标官能团。

### 1.3 电子效应

官能团对反应的影响通过两类电子效应传播：

- **诱导效应**：通过 $\sigma$ 键传递的电负性影响，随距离迅速衰减，一般超过三根键
  就可以忽略。
- **共轭效应**：通过共轭 $\pi$ 体系传递的电子密度重排，作用距离远，常在亲电取代的
  定位规则中起决定作用。

一条简单判据：如果取代基通过诱导或共轭把电子推向反应中心，它使亲电试剂更难进攻，
却使亲核试剂更容易进攻；反之亦然。这条规则在 §2 与 §3 中被反复使用。

### 1.4 官能团的酸碱性

官能团的反应性与它的酸碱性直接相关，因为亲核性与离去能力都取决于相关原子的
电子密度。下表给出若干常见官能团在水中的近似 pKa 以及由此得到的直觉。

| 官能团 | 共轭酸 pKa | 酸性强弱 | 说明 |
| ------ | ---------- | -------- | ---- |
| 羧酸 R–COOH | 约 5 | 较强 | 共轭碱共振稳定 |
| 酚 Ar–OH | 约 10 | 中等 | 苯环参与离域 |
| 醇 R–OH | 约 16 | 较弱 | 负电荷集中 |
| 水 H₂O | 约 16 | 较弱 | 参照物 |
| 铵 R–NH₃⁺ | 约 10 | 显碱性 | 氮上孤对电子 |
| 烷烃 R–H | 约 50 | 几乎无 | 极难去质子 |

记忆要点是：共轭碱越稳定，酸性越强。羧酸远强于醇，是因为羧酸根可以通过两个氧
原子共振离域负电荷，而醇盐只能把负电荷留在一个氧上。这条「稳定性决定酸性」的
规则同样适用于判断离去基团与亲核试剂，因此它是本章反复使用的一把尺子。

## 2. 亲核取代 Nucleophilic Substitution

卤代烃 R–X 上的碳原子带部分正电荷，是亲电中心。亲核试剂 Nu⁻ 带着一对
孤对电子进攻它，把卤离子 X⁻ 取代下来，这就是亲核取代：

$$
\mathrm{Nu^-} + \mathrm{RX} \;\longrightarrow\; \mathrm{R{-}Nu} + \mathrm{X^-} .
$$

根据决定速率的步骤不同，机理分为两大类。

### 2.1 SN1 机理

SN1 是「取代、亲核、单分子」的缩写，决定速率的步骤只涉及底物一个分子。它分两步：

1. 碳卤键异裂，卤离子离去，形成一个平面的碳正离子中间体。
2. 亲核试剂从任意一面进攻这个平面中心。

因为中间体是平面构型的，进攻可以发生在两侧，所以若底物是手性的，产物通常得到
接近外消旋的混合物。速率方程为

$$
v = k\,[\mathrm{RX}] ,
$$

与亲核试剂浓度无关。碳正离子越稳定，反应越快，因此三级卤代烃最快、一级最慢。

### 2.2 SN2 机理

SN2 是「双分子」机理，亲核试剂的进攻与卤离子的离去同时发生，经过一个五配位的
过渡态。因为亲核试剂从背面进攻，产物的构型发生**构型翻转**，即瓦尔登翻转。

速率方程对两个物种各为一级：

$$
v = k\,[\mathrm{RX}][\mathrm{Nu^-}] .
$$

空间位阻是决定性因素：三级碳被三个烷基挡住背面，几乎无法发生 SN2；甲基与一级碳
最容易。表 2 总结了两者的区别。

| 特征 | SN1 | SN2 |
| ---- | --- | --- |
| 速率方程 | $k[\mathrm{RX}]$ | $k[\mathrm{RX}][\mathrm{Nu^-}]$ |
| 决速步 | 碳正离子形成 | 协同过渡态 |
| 立体化学 | 外消旋化 | 构型翻转 |
| 底物偏好 | 三级 > 二级 > 一级 | 甲基 > 一级 > 二级 |
| 溶剂影响 | 极性质子溶剂促进 | 极性非质子溶剂促进 |

### 2.3 影响机理选择的因素

- **底物结构**：碳正离子越稳定，SN1 越占优；背面越空旷，SN2 越占优。
- **亲核试剂强度**：强亲核试剂（如 CN⁻、RS⁻）推动 SN2。
- **离去基团**：离去能力越强（I⁻ > Br⁻ > Cl⁻ ≫ F⁻），两类反应都越快，因为
  两者都要断这根键。
- **溶剂**：极性质子溶剂通过氢键稳定阴离子、包住亲核试剂，降低亲核性，偏向 SN1；
  极性非质子溶剂把亲核试剂「裸露」出来，偏向 SN2。

### 2.4 反应能量图

机理的差别在能量—反应坐标图上看得最清楚。SN1 的图有两个峰、一个谷（中间的碳正
离子），SN2 只有一个峰，因为进攻与离去是协同发生的。

```text
SN1:  底物 ──峰──► 碳正离子(谷) ──峰──► 产物
      两步，速率只与底物浓度有关

SN2:  底物 ──────────峰──────────► 产物
      一步，五配位过渡态，速率与两者都有关
```

谷的存在有可观察的后果：碳正离子中间体有一定的寿命，因此可以发生重排，也可以
先与溶剂反应。协同机理没有中间体，产物分布完全由过渡态的几何决定，这正是 SN2
的构型翻转如此干净的原因。参见 §4.2，构型判断正是建立在这个几何图像之上。

### 2.5 邻基参与

有时反应速率远超根据底物结构应有的水平，原因通常是分子内存在一个邻近的富电子
基团。它先与反应中心成键、把离去基团挤走，随后又被真正的亲核试剂取代。这种
「内部接力」称为邻基参与。它有两个可识别的特征：速率异常高，以及两次背面进攻
导致两处构型都被翻转、净结果是构型保留。

```text
            亲核试剂强度 ↑
   SN1  ←──────────────────────→  SN2
   三级碳                          甲基碳
   弱亲核                          强亲核
   极性质子溶剂                    极性非质子溶剂
```

> 一个实用的判断顺序：先看底物的取代级数，再看亲核试剂强弱，最后看溶剂。三步走下来，
> 大多数题目的机理选择就可以确定。

## 3. 取代与消除的竞争

强碱既能进攻碳原子发生取代，也能夺取 $\beta$ 氢发生消除。消除反应生成烯烃：

$$
\mathrm{R{-}CH_2{-}CH_2{-}X} + \mathrm{B^-}
\;\longrightarrow\;
\mathrm{R{-}CH{=}CH_2} + \mathrm{HB} + \mathrm{X^-} .
$$

### 3.1 E1 与 E2

与取代类似，消除也分单分子（E1）与双分子（E2）机理。E1 与 SN1 共享碳正离子中间体，
因此两者常常同时发生；E2 与 SN2 一样是协同过程，但碱从 $\beta$ 位夺取氢、卤离子
从 $\alpha$ 位离去，二者处于**反式共平面**才最有利于轨道重叠。

### 3.2 温度与碱体积的影响

- 高温有利于消除，因为消除生成两个分子，熵增更大。
- 体积大的强碱（如叔丁醇钾）难以接近碳原子，却容易抓到暴露的 $\beta$ 氢，因此偏向
  E2 消除。
- 高温加小体积亲核试剂偏向取代，高温加大体积强碱偏向消除。

### 3.3 扎伊采夫规则

当存在多个 $\beta$ 氢时，消除优先脱去能生成**更稳定烯烃**的那一个，通常是取代基
更多、更稳定的烯烃，这就是扎伊采夫规则。它的电子学解释是：过渡态带有部分碳正离子
性质，连接更多给电子基团的双键在过渡态中被更好地稳定。

### 3.4 碱的强度与消除选择性

消除需要碱夺取 $\beta$ 氢，因此碱的强度与体积直接决定反应走向。下表列出常见碱的
相对强度与对应倾向。

| 碱 | 强度 | 主要倾向 | 原因 |
| -- | ---- | -------- | ---- |
| 水 / 醇 | 弱 | E1（伴随 SN1） | 不足以夺取氢 |
| 氢氧根 | 中等 | SN2 为主 | 体积小、亲核性强 |
| 乙醇钠 | 较强 | E2 为主 | 碱性强于亲核性 |
| 叔丁醇钾 | 强且体积大 | E2 专一 | 体积大阻碍取代 |
| 二异丙基氨基锂 | 极强 | 定向消除 | 几乎不亲核 |

选择碱的经验是：想得到取代产物就用小体积的亲核试剂，想得到消除产物就用大体积的
强碱并适当升高温度。这与 §3.2 的定性结论一致，只是把方向换成了具体的试剂。

## 4. 立体化学 Stereochemistry

### 4.1 手性中心

一个碳原子若连接四个互不相同的基团，就称为手性中心。这样的分子与其镜像不能重合，
就像左手与右手。含有手性中心的分子通常有光学活性，能使平面偏振光旋转，左旋记
$(-)$，右旋记 $(+)$。

### 4.2 R/S 记号

确定手性中心绝对构型的步骤是：

1. 按原子序数从大到小排列四个取代基，得到优先级 $a > b > c > d$。
2. 把优先级最低的 $d$ 指向远离观察者的方向。
3. 从 $a$ 到 $b$ 到 $c$ 画圈：顺时针为 $R$（拉丁文 rectus，右），逆时针为 $S$（sinister，左）。

如果 $d$ 不方便指离观察者，可以先按当前视角判断，再反转结果。这个「反转」源自
投影的改变，是初学者最容易出错的地方。

### 4.3 对映体、非对映体与内消旋

- **对映体**是互为镜像的两种构型，物理性质几乎相同，只在手性环境中表现不同。
- **非对映体**含有两个或以上手性中心，但只在一个中心上构型相反，它们的物理性质
  差别明显，可以常规柱层析分离。
- **内消旋体**分子内部存在对称面，两个手性中心构型相反，整体不具光学活性。

| 关系 | 手性中心差异 | 物理性质 | 光学活性 |
| ---- | ------------ | -------- | -------- |
| 对映体 | 全部相反 | 几乎相同 | 等量相反 |
| 非对映体 | 部分相反 | 不同 | 不同 |
| 内消旋体 | 分子内对称 | — | 无 |

### 4.4 手性合成与拆分

若反应从非手性原料出发，生成的产物通常是外消旋体，因为两条路径的过渡态能量相等。
要得到单一对映体，必须引入手性信息：可以是手性催化剂、手性辅基，或者先合成
外消旋体再用手性拆分手段分离。工业上常用酶催化，因为酶本身就是高效的手性催化剂。

### 4.5 对映体过量

衡量手性合成纯度最常用的量是对映体过量（enantiomeric excess, ee）：

$$
\mathrm{ee} = \frac{[\mathrm{R}] - [\mathrm{S}]}{[\mathrm{R}] + [\mathrm{S}]} \times 100\%,
$$

其中 $[\mathrm{R}]$ 与 $[\mathrm{S}]$ 是两种对映体的浓度。外消旋体对应 $\mathrm{ee} = 0$，
单一对映体对应 $\mathrm{ee} = 100\%$。知道 ee 后还可以由旋光度反推组成：

$$
[\alpha]_{\text{obs}} = \mathrm{ee} \times [\alpha]_{\text{pure}} .
$$

这条关系提供了从实验测量回到分子组成的桥梁，是手性分析中最基本的计算。

## 5. 机理与立体化学的综合分析

把前面的工具合起来看一个典型问题：一级卤代烃在强亲核试剂下的反应。底物是一级碳，
背面不受阻，强亲核试剂在极性非质子溶剂中几乎裸露，因此按 SN2 进行，速率与两个
物种各为一级，产物构型翻转。如果把同一底物换成三级，SN1 占优，速率只与底物有关，
产物接近外消旋。再提高温度并换用大体积强碱，则 E2 消除成为主反应，且遵守扎伊采夫
规则。

把三个因素整理成一张判断表，可以让分析过程标准化：

| 观察条件 | 倾向 | 立体化学后果 |
| -------- | ---- | ------------ |
| 一级碳 + 强亲核试剂 | SN2 | 构型翻转 |
| 三级碳 + 极性质子溶剂 | SN1 | 外消旋化 |
| 二级碳 + 大体积强碱 + 高温 | E2 | 反式共平面消除 |
| 二级碳 + 弱碱 + 低温 | SN2 或 SN1 | 视溶剂而定 |

这张表不是用来背的，而是用来核对推理是否完整：只要某个条件没有覆盖到，就说明
分析里还缺一环。

### 5.1 选择性的三个层次

真实反应往往同时面临三类选择，把它们分开考虑能避免混淆：

- **化学选择性**：一种官能团先反应，另一种暂不反应。
- **区域选择性**：官能团在分子的哪个位置反应。
- **立体选择性**：反应偏好生成哪一种立体异构体。

以烯烃的亲电加成为例，马氏规则解决的是区域选择性，而加氢的顺式与反式之别则属于
立体选择性。下表把它们与本章前面的机理联系起来。

| 选择性 | 决定因素 | 本章对应内容 |
| ------ | -------- | ------------ |
| 化学选择性 | 官能团的电子与位阻 | §1.2 官能团一览表 |
| 区域选择性 | 中间体与过渡态稳定性 | §3.3 扎伊采夫规则 |
| 立体选择性 | 过渡态几何 | §2.2 SN2 构型翻转 |

把这张表与 §5 开头的判断表合起来读，就得到一张完整的分析清单：先判断有几种可能
的产物，再逐一判断哪一类选择性起作用，最后核对立体化学。

> 这类问题的标准解法是「先定机理、再定立体化学、最后定产物分布」。机理决定了速率
> 方程与中间体构型，立体化学决定了手性结果，产物分布则是两者共同作用的统计结果。

## 6. 本章小结

本章从官能团的电子结构出发，建立了反应性的判断框架。§1 分类常见官能团并引入诱导
与共轭效应；§2 系统对比 SN1 与 SN2 的速率方程、立体化学与影响因素；§3 讨论取代与
消除的竞争，给出 E1、E2 的区别与扎伊采夫规则；§4 建立手性中心、R/S 记号以及对映体、
非对映体、内消旋体的区分；§5 把机理与立体化学综合到实际问题的分析流程中。掌握这条
链条后，多数有机反应题都可以按步骤推理而不是死记。
