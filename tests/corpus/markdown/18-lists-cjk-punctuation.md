# 中文列表与全角标点

在中文技术写作里，标点符号通常使用全角形式，句末的句号写作「。」，并列成分之间用「、」分隔，冒号和分号也各自占一个汉字宽度。

无序列表适合罗列并列的要点，每一项末尾都用全角句号收尾。

- 第一项说明接口的返回值为空（null），调用方必须自行判断。
- 第二项介绍超时时间的默认取值，常用值为三十秒。
- 第三项提醒读者：重试次数建议不超过三次；超过之后应当直接失败。

有序列表适合描述有先后顺序的步骤，序号与正文之间同样使用全角标点。

1. 首先初始化配置对象，并读取环境变量中的密钥。
2. 然后建立连接，检查握手阶段返回的状态码。
3. 最后关闭连接，释放占用的文件句柄（file handle）。

引用书名时使用《》，例如《设计数据密集型应用》一书中讨论了分布式系统的一致性模型；引号内部再引用时改用「」。
