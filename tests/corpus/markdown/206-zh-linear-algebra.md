# 线性代数核心概念

线性代数研究向量空间以及作用于其上的线性变换。它的抽象层次时常让初学者感到吃力，但只要抓住一条主线——矩阵就是线性变换在给定基下的坐标表示——绝大多数概念都会连成一体。

## 向量空间

向量空间由一组向量构成，允许做加法与数乘，并满足若干公理。真正的关键不在于向量本身长什么样，而在于哪些操作被允许。

- 线性组合把若干个向量按系数加权求和。
- 生成集是指其所有线性组合能够覆盖整个空间的集合。
- 线性无关意味着任一向量都不能被其余向量线性表示。
- 基是既线性无关又能生成整个空间的集合，空间中每个向量在给定基下的坐标是唯一的。

维度就是基中向量的个数，它与基的具体选择无关。这条结论保证了维度是空间的内在属性。

## 矩阵与线性变换

矩阵的列可以看作基向量的像，于是矩阵乘法自然对应变换的复合。理解这一点之后，矩阵乘法的定义就不再需要死记。

| 概念 | 代数意义 | 几何意义 |
| --- | --- | --- |
| 矩阵乘法 | 变换复合 | 先做一次再另做一次 |
| 行列式 | 体积的缩放因子 | 是否发生塌缩 |
| 秩 | 像空间的维度 | 变换后保留的独立方向数 |
| 零空间 | 被映到原点的向量集合 | 被压扁的方向 |

行列式为零等价于矩阵不可逆，也等价于列向量线性相关。三种说法从不同角度描述同一件事，这正是线性代数优雅的地方。

## 矩阵分解

分解的目的是把复杂矩阵写成若干结构简单的矩阵之积。

1. 消元分解把矩阵写成下三角与上三角之积，用于求解线性方程组。
2. 正交三角分解把矩阵写成正交矩阵与上三角之积，数值上更稳定。
3. 特征分解适用于可对角化的方阵，把变换拆成沿特征方向的独立缩放。
4. 奇异值分解对任意矩阵都成立，它给出的奇异值刻画了各主方向的能量。

奇异值分解在数据压缩与降维中极为常见。保留最大的若干奇异值，就得到原矩阵在低秩约束下的最优近似。

> 数值计算与理论推导的差别，往往体现在稳定性而非正确性上。一个在实数域成立的公式，在浮点运算中可能因为消去误差而失效，因此实践中更偏好正交变换。

## 特征值与特征向量

特征向量是变换作用下方向保持不变的向量，特征值则是该方向上的缩放倍数。求解特征值需要展开特征多项式，但高阶情形下直接求根并不可靠，实际计算通常借助迭代方法。

特征值决定了许多动态系统的长期行为：模最大的特征值主导增长或衰减速率，而特征向量的方向描述了系统的稳态比例。这种把复杂耦合系统还原为若干独立模式的思想，贯穿了线性代数的几乎所有应用。
