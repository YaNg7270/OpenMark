# 机器学习入门

机器学习的核心命题是：从有限的观测中归纳出可以推广到新样本的规律。它把要解决的问题表述成在假设空间里寻找一个函数，使得该函数在训练数据上的误差尽可能小，同时在新数据上依然表现良好。这两个目标之间存在张力，解决这种张力是整门学科的主线。

## 监督学习的基本框架

监督学习给定输入与标签的成对样本，目标是学习从输入到输出的映射。

- 分类问题输出离散标签，关注决策边界的位置。
- 回归问题输出连续数值，关注拟合误差的分布。
- 结构化预测输出复杂的组合对象，例如序列标注或语法树。

训练过程通常转化为优化问题：定义损失函数度量预测与真实值的差距，再用迭代方法调整参数。模型的表达能力、损失函数的形状与优化算法三者共同决定最终结果。

## 损失函数

损失函数把评价标准写成可微的目标，因此它的选择直接决定模型在意什么样的错误。

| 任务 | 常用损失 | 对异常值敏感度 |
| --- | --- | --- |
| 回归 | 平方误差 | 高 |
| 回归 | 绝对误差 | 低 |
| 分类 | 交叉熵 | 适中 |

平方误差对大偏差的惩罚是二次增长，因此少数离群点可能主导梯度方向。绝对误差更稳健，但在零点不可导，需要额外处理。交叉熵来自最大似然估计，与概率输出天然匹配，并且梯度形式简洁，是分类任务的默认选择。

## 过拟合与正则化

过拟合指模型把训练数据中的噪声也当作规律记住，从而在新数据上表现变差。它的典型征兆是训练误差持续下降而验证误差开始上升。

> 判断过拟合不能只看训练误差。真正有意义的信号是训练与验证两条曲线之间的间隔，以及这个间隔是否随着训练继续而扩大。

缓解手段大致分为三类。

1. 数据层面：增加样本、数据增强、主动学习补充困难样本。
2. 模型层面：降低容量、加入正则项、使用早停。
3. 训练层面：集成多个模型、交叉验证选择超参数。

常见的正则项包括参数平方和与参数绝对值之和，前者让权重整体变小，后者鼓励稀疏解，从而起到特征选择的作用。

## 模型评估

评估方法决定了我们能否相信测得的性能。

- 留出法简单，但结果依赖单次划分，方差大。
- 交叉验证把数据轮换使用，估计更稳定，代价是计算量成倍。
- 时间序列必须按时间切分，随机划分会造成信息泄漏。

数据泄漏是实践中最隐蔽也最致命的错误之一：如果预处理中的标准化使用了包含验证集的统计量，报告的性能就会被高估。任何在划分之前进行的全局变换，都应当重新审视。

最后，离线指标与线上效果并不总是一致。离线评估只能保证模型在历史分布下表现良好，一旦用户行为因模型上线而改变，就需要借助随机对照实验来确认真实收益。
