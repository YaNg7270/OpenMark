# 计算机图形学：光栅化、着色器与抗锯齿

计算机图形学（computer graphics）的实时渲染管线，归根到底是在回答一个问题：如何把三维空间里的几何体，又快又像地画到二维屏幕上。这个过程中最关键的三步是光栅化、着色与抗锯齿。

## 光栅化

光栅化（rasterization）把三角形这样的图元转换成屏幕上的像素覆盖。它先算出三个顶点投影到屏幕后的坐标，再逐像素判断哪些像素的中心落在三角形内部。

- 顶点着色器（vertex shader）负责把顶点从模型空间变换到裁剪空间；
- 图元装配把顶点连成三角形；
- 光栅化阶段对每个像素插值出属性，如深度、uv、法线。

| 阶段 | 输入 | 输出 |
| --- | --- | --- |
| 顶点处理 | 顶点属性 | 裁剪空间坐标 |
| 光栅化 | 三角形 | 像素片段 |
| 片元处理 | 插值属性 | 最终颜色 |

## 着色器

着色器（shader）是运行在 GPU 上的小程序，决定了每个像素最终显示成什么颜色。它天生是并行的：同一个片元着色器会同时处理成千上万个像素，因此绝对不能在里面依赖执行顺序。

```glsl
void main() {
  vec3 color = mix(vec3(0.0), vec3(1.0), uv.y);
  fragColor = vec4(color, 1.0);
}
```

> 在 GPU 上，写代码的第一原则是「让每个像素只关心自己」，任何跨像素的读取都要靠纹理。

现代管线里常见的着色阶段包括顶点、片元，以及用于几何放大的几何着色器或在光追中扮演关键角色的光线生成着色器。光照计算则多在片元阶段完成，从简单的 Lambert 漫反射到基于物理的渲染（PBR），本质都是把材质参数代进反射方程。

## 抗锯齿

锯齿（aliasing）来自采样不足：一个像素要么完全在三角形内，要么完全在外，边缘就出现了阶梯。

1. 超采样（SSAA）用更高分辨率渲染再缩小，效果好但开销大；
2. 多重采样（MSAA）只对边缘做多子采样，是实时渲染的主流；
3. 时间性抗锯齿（TAA）借助历史帧累积，代价低，但容易产生拖影。

MSAA 只解决几何边缘的锯齿，对纹理内部的走样无能为力，这类问题要靠 mipmap 与各向异性过滤来解决。而 TAA 的历史帧一旦被错误的运动向量污染，就会出现鬼影（ghosting），因此必须为动态物体提供准确的运动向量。

## 性能与取舍

GPU 的性能瓶颈通常分为顶点受限与像素受限两类。若场景多边形极多而分辨率不高，就优先优化几何；反之则应减少过度绘制（overdraw）。半透明物体尤其昂贵，因为它们无法依赖深度测试提前丢弃，只能按从后到前的顺序混合，这就进一步放大了填充率压力。

## 小结

光栅化决定画在哪，着色器决定画成什么样子，抗锯齿决定边缘够不够干净。三者共同构成实时渲染的性能与画质边界。
